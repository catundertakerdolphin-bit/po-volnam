# По волнам

Музыкальная WebGL-аркада: плыви дельфином сквозь подводный мир, который рождается из звука.

**[Играть →](https://catundertakerdolphin-bit.github.io/po-volnam/)**

**[Версия с рекламными щитами →](https://catundertakerdolphin-bit.github.io/po-volnam/billboards.html)**

В отдельной версии щиты разных размеров появляются каждые 2,5 секунды и движутся вместе с миром. На каждом третьем маленький рабочий наклеивает плакат. Файл `billboards.html` содержит всю игру и четыре изображения брендов; исходная версия доступна по основной ссылке.

## Управление

- Два пальца на трекпаде или стрелки / A и D — поворот.
- Тап по игре или пробел — прыжок.
- На телефоне: двигай нижний круг влево-вправо; короткое касание — прыжок.
- Кнопка ▶ запускает музыку и заплыв.
- «Свой трек» позволяет выбрать аудиофайл. Анализ происходит в браузере; файл не отправляется на сервер.

## Игра

Последняя версия рифа (v6): разнофактурные известняковые скалы, серый дельфин, гладкие боковые срезы, волны и каустика, связанные с преломлением света и всплесками.

Встроенный оригинальный демотрек **Tidal Sketch** длится 72 секунды и синтезируется прямо в браузере.

## Запуск

Вся игра находится в одном `index.html`; установка зависимостей и сборка не нужны. Открой файл в современном браузере с WebGL 2 или используй ссылку выше. Для загрузки Three.js r160 с jsDelivr нужен интернет.

GitHub Pages публикует корень ветки `main`. Обновление `index.html` в этой ветке обновляет игру.
